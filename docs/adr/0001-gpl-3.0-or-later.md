# 0001. The project is GPL-3.0-or-later

- Status: accepted, 2026-10-06
- Decided by: Torben Gräber, the sole copyright holder
- Reverses: the MIT licence, adopted on 2026-09-24 (5f3b877, 3d76869)

## Context

Until now the repository was MIT, and MIT was a goal, not a default. It
decided three things that had nothing to do with licensing on their own.

- **The shell.** The plugins were JUCE plugins until 2026-09-24. JUCE 8 is
  AGPLv3-or-commercial, and it was "the last copyleft dependency here and the
  only reason this repository was not MIT", so it was removed (3d76869).
  iPlug2 (zlib) took the formats, on Steinberg's VST3 SDK, which has been MIT
  since 3.8.
- **The editor.** JUCE's editor went with JUCE, and the editors were drawn
  again in Solid, inside iPlug2's WKWebView (f8af871).
- **The dependencies.** No crate was taken that would need a row of its own in
  THIRD_PARTY_LICENSES.md. Every byte in the artefact had to be "permissive AND
  ACCOUNTED FOR" (spectro-core's Cargo.toml, as it read until this decision),
  so the FFT, the lock-free queues and the shared memory were all written by
  hand.

The licence was GPL-3.0-or-later once before, for a day (ef686b0). nih-plug's
VST3 export linked vst3-sys, which is GPLv3. That premise was out of date, and
the project went back to MIT (5f3b877).

That chain has a price, and the time since has itemised it. The WebView editor
is now the main source of cost:

- inside a host, the page counts as hidden, so it gets almost no
  `requestAnimationFrame`, and its timers are throttled to 2–3 Hz;
- an iPlug2 editor message is capped at 64 KB, and its payload is base64'd
  without a word;
- `OnUIClose` never fires;
- four iPlug2 patches are proposed and not applied, and clap-validator holds
  17 known failures;
- the clipboard and the file panels are hand-written Objective-C++;
- there is no API to mark the host's set dirty after an import;
- the CMake deploy order needs hacks.

None of these is about the sound. All of them come from the shell that MIT
chose.

## Decision

Everything in this repository is licensed **GPL-3.0-or-later**: version 3 of
the GNU General Public License or, at the recipient's option, any later
version. Version 3 is the newest, and there is no version 4. Torben Gräber
holds the copyright in all of it, so he can relicense it alone.

- `LICENSE` is the unmodified text of GPLv3, as gnu.org publishes it.
- Every source file opens with two lines: `SPDX-License-Identifier:
  GPL-3.0-or-later` and `Copyright (C) 2026 Torben Gräber`.
- Every dependency must be under a licence that GPLv3 can take in. The
  allowlist is MIT, Apache-2.0, BSD-2-Clause, BSD-3-Clause, ISC, Zlib,
  MPL-2.0, Unicode-3.0, CC0-1.0, Unlicense and GPL-3.0. JUCE's AGPLv3 is also
  allowed: GPLv3 section 13 lets a GPLv3 work be combined with an AGPLv3 one.
  Anything else is refused. That includes GPL-2.0-only, which cannot be
  combined with GPLv3.

## Consequences

- **The licence no longer decides the shell or the dependencies.** JUCE can be
  the shell again ([0002](0002-juce-native-editors.md)), and established crates
  can replace hand-written code ([0003](0003-established-rust-crates.md)).
- **A plugin is a combined work.** It combines our GPLv3 code with JUCE's
  AGPLv3 code. Our part stays under GPLv3. AGPLv3's own section 13, on
  interaction through a network, applies to the combination as such.
- **The source travels with every release.** Whoever receives a plugin or a
  module has the right to its source (GPLv3 section 6). So every release names
  the tag it was built from and links that tag's tree.
- **Permissive dependencies keep their notices.** Our licence does not replace
  their conditions. THIRD_PARTY_LICENSES.md stays, ships in every bundle and
  every module, and is checked against what ships. cargo-deny holds every Rust
  crate to the allowlist, and cargo-about writes the crates' notices.
- **The schwung-ducker port keeps its upstream notice.** The Side-Chain's MIDI
  trigger is ported from MIT code, © 2026 Charles Vestal. MIT allows that code
  in a GPLv3 work on one condition: its notice stays. So it stays, beside ours.
- **Copies released under MIT keep that licence.** Whoever has one keeps the
  rights it came with. What is released from 2026-10-06 on is
  GPL-3.0-or-later.
