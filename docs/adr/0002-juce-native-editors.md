# 0002. JUCE is the shell, and the editors are native

- Status: accepted, 2026-10-06
- Decided by: Torben Gräber
- Reverses: iPlug2 with Solid editors in a WebView, adopted on 2026-09-24
  (e4b0d07, 3d76869, f8af871)
- Follows from: [0001](0001-gpl-3.0-or-later.md)

## Context

The Trance Gate began as a JUCE plugin with a JUCE editor. JUCE was removed on
2026-09-24 for its licence, not for any technical reason. Of the 62 distinct
`juce::` symbols the build used, 26 were drawing, 8 were the format wrappers
and 12 were utility, and none was DSP, which was already Rust (3d76869).
iPlug2 took the formats: VST3, AU and CLAP, under zlib. The editor was drawn
again in Solid and Vite, and loaded into iPlug2's WKWebView over a custom URL
scheme (f8af871). Every later plugin followed the same pattern.

The DSP has never been the problem. The web editor has become the most
expensive part of the project, item by item:

- **Inside a host, the page counts as hidden.** It gets almost no
  `requestAnimationFrame`, and its timers are throttled to 2–3 Hz. So every
  animation was moved onto timers and checked by a test of its own
  (`editor_timing`).
- **Every byte crosses a message bridge.** A message is capped at 64 KB, and
  its payload is base64'd without a word. Each product added numbered tags, and
  a test holds both sides of the bridge to one table (`editor_tags`).
- **`OnUIClose` never fires.**
- **The validators are held to manifests.** Four iPlug2 patches are proposed
  and not applied, and clap-validator has 17 known failures
  (`tests/validators.known.json`).
- **The clipboard and the file panels are hand-written Objective-C++**
  (`Clipboard.mm`, `FileDialog.mm`), so they exist on macOS only.
- **An import cannot mark the host's set dirty.** iPlug2 has no API for it.
- **The CMake deploy order needs hacks.**

Each of these was worked around, never fixed, because each fix lies in WebKit
or in iPlug2. With 0001 the licence no longer rules JUCE out. JUCE's native
components, its clipboard and file chooser, and its host notifications cover
each item above.

## Decision

- **JUCE 9 is the plugin shell**, under AGPLv3, and VST3 is the only format.
  AU and CLAP are dropped. The plugins build, test and release on macOS,
  Windows and Linux.
- **The editors are native JUCE Components.** They look and behave as the Solid
  editors do, and they are built to Ultraviolet 1.1.0. Their design tokens are
  generated from `design/scheme/project/tokens.json`.
- **iPlug2, the WebView, Solid and the ui-kit go.** Solid and Vite stay the
  choice for browser apps, such as the documentation site.
- **The Rust engines are reached through their C ABI**, as they are today. The
  headers are generated by cbindgen ([0003](0003-established-rust-crates.md)).
- **Old Live sets open as they were saved.** A set saved with the iPlug2 VST3
  builds must load the JUCE build with the same settings. That requires
  `JUCE_VST3_COMPATIBLE_CLASSES` and the compatible parameter IDs. A spike
  proves both in Live before anything is deleted. If Live does not honour
  them, the work stops and the owner decides. A JUCE fork would be a
  workaround.

## Consequences

- **The hidden-page throttling goes, and the bridge goes with it.** An editor
  repaints from a timer or the display's vblank, and reads the engine's
  published snapshots directly. There are no message tags, no base64 and no
  string caps.
- **The platform glue is JUCE's.** `juce::SystemClipboard` and the asynchronous
  `juce::FileChooser` replace the Objective-C++ glue on all three systems. An
  import marks the set dirty with one call: a non-parameter state change
  reported to the host.
- **The validators run in their strictest modes.** pluginval runs at
  strictness 10 with the GUI, alongside Steinberg's own validator. The
  manifests of known failures are no longer needed.
- **Old AU and CLAP instances must be re-inserted.** The CHANGELOG says so
  when the change ships.
- **The plugins are combined works under GPLv3 and AGPLv3**
  ([0001](0001-gpl-3.0-or-later.md)), and every release links its source.
