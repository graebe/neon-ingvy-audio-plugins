# Hint

The one line of `hint` text at the bottom edge of every window, above a `line-100` rule: the window's interaction conventions, verb in `ink`, the rest in `ink-muted`, clauses separated by en dashes. Three clauses at most; if a window needs more, the interaction is too clever. The tips are left-aligned; the `Signature` closes the bar on the right. Consumer provides: the clauses as (verb, rest) pairs.
