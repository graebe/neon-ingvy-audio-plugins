# Select

A 28px `bg-200` field with a `value`-style label and a 1px chevron; the open list is a `bg-100` box with a `uv` border, one row per option, the current option in `uv`, the row under the pointer `bg-300`. Use it for enumerations (rate divisions, pattern slots, modes) with 3–12 options; two options are a `Toggle`, more than 12 want a knob with a stepped readout. Consumer provides: options, value, onChange, min-width.
