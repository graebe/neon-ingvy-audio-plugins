# Ring

A circle of segments, one per step, for the step count and the playhead: unlit segments `ink-dim`, active `uv`, the current step `ink`, on a `line-100` track. The `readout` number sits in the centre with a `label` under it. Use the 240px ring once per window as the window's face, or the 120px variant next to a control row. Consumer provides: step count, active count, playhead index, the centre value and label. The ring is display; the count is changed elsewhere (a knob or the grid).
