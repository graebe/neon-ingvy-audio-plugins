# TextField

A 28px (`control-h`) field for a name or a value typed in: a `bg-200` well with a `line-200` hairline, radius 0, `value` text in `ink`, padded `space-2`; an empty field shows what belongs there in `ink-muted` ("name this bus"). While it is being typed into, the border is `uv` with `glow-focus`, as a `Readout` being edited. Enter keeps the text and a click elsewhere keeps it too; Escape cancels and puts the last value back. A field commits once per edit, never per keystroke, and it never shows more than the plugin keeps (its length limit is the plugin's). Use it for text the user names, a bus or a slot; a number belongs to a knob's `Readout`, which turns into this field on a click. Consumer provides: value, placeholder, maximum length, an accessible label, the info string, and what a commit does.
