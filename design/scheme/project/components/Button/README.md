# Button

A `bg-200` rectangle with a `line-200` hairline, 28px high, text in `button` style, optionally led by a 16px `Icon` at an 8px gap. Default is the quiet variant; `primary` (`uv` fill, `on-uv` text, `glow-led`) at most once per window for the action the window exists for. `icon` is the 28px square icon-only form for transport (play, pause, stop, record), the window verbs (copy, paste, export, export all, import), loop, link and power; a latching icon button shows its state with `on` (lit like a step, its glyph in `on-uv`), record with `rec on` in `red`, its glyph in `bg-000` because `on-uv` on red falls under 3:1. Adjacent icon buttons sit in a `ph-transport` (transport) or `ph-actions joined` (window verbs) group sharing hairlines; labelled window verbs stack in `ph-actions stack` at equal width. Placement is in `Actions`. Buttons are for actions, never for toggling a parameter: that is a `Toggle`. Text labels are verb-first, sentence case, two words at most: "Copy slot". Every button declares its info string (`Hint`), which is also its accessible description. Consumer provides: label and/or icon, variant, on, disabled, onClick, the info string, and an `aria-label` for icon-only buttons.
