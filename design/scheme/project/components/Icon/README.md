# Icon

A 16px machine glyph, inline SVG, 1.5px stroke with square caps, drawn in `currentColor` so it takes the colour of its control (`ink` at rest, `on-uv` on a lit button, `bg-000` on the red record button, `ink-dim` disabled). Fifteen glyphs: play, pause, stop, record, loop, copy, paste, export, export-all, import, shuffle, reset, link, chevron, power; the files are under Icons. Export, export-all and import are one family with copy and paste, the window's verbs on its content: an arrow up out of an open tray (save the current item to a file), the same arrow over a doubled tray (save every slot, a bank, to one file), and an arrow down into the tray (load a file). Use an icon only where it replaces a verb on a control that acts (transport, copy/paste, export/import, loop, reset) or a caret; never beside a parameter label, never as decoration, never for a state that an LED already shows. An icon-only button carries an `aria-label` with the verb. Consumer provides: the glyph name and, for icon-only use, the label.
