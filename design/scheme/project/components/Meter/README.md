# Meter

A level, read-only: a 12px (`space-3`) `bg-200` bed with a `line-100` hairline, radius 0, filled from the left in flat `uv` with its glow, as wide as the row gives it. No gradient, no peak colours, no transition: the fill jumps to the level as every value does (Motion). The scale is the plugin's, and a meter is linear in dB rather than in amplitude, so a quiet part that is plainly audible does not read as an empty bar. A meter whose signal is measured but goes nowhere (an input that is not being published) fills in `line-200` without glow (`off`), so "nothing is playing" and "playing, going nowhere" look different. A meter is display; a level the user sets is a `Slider`. Consumer provides: the level 0–1 on the plugin's scale, whether it is live, and an accessible label (`role="meter"`).
