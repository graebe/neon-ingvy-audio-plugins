# Readout

The number under a control: a 28px `bg-000` box with a `line-200` hairline, `value` text centred, the unit in `ink-muted`. Click to edit: the border and `glow-focus` turn `uv`. The large `readout` text style (28px, no box) is a different thing: the one number a window is about, used once, usually inside a `Ring`. Consumer provides: the formatted string (the readout never formats), unit, editing, disabled.
