# Readout

The number under a control: a 28px `bg-000` box with a `line-200` hairline, `value` text centred, the unit in `ink-muted` after the number. One click types into it: the box becomes a field with the value selected, its border `uv` with `glow-focus`; Enter or a click elsewhere keeps what was typed, Escape abandons it, and Enter on the focused knob opens it from the keyboard. The plugin parses the text in the readout's own units ("40 ms", "1/8T"), so the readout's info string says what it accepts ("Rate value — click to type a division, such as 1/16 or 1/8T."). The large `readout` text style (28px, no box) is a different thing: the one number a window is about, used once, usually inside a `Ring`. Consumer provides: the formatted string (the readout never formats), unit, editing, disabled, the info string, and what to do with typed text.
