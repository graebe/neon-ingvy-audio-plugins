# Slider

Use a slider instead of a knob only when the parameter is a level (wet, dry, gain) or a mixer-style row of levels; knobs are the default. Vertical 120px rail in a `bg-200` bed, `uv` fill from the bottom, an `ink` thumb; a horizontal variant (`h`, 160px) for a single time-like parameter (swing). Consumer provides: label, value 0–1, readout, orientation, disabled. Do not mix vertical and horizontal sliders in one row.
