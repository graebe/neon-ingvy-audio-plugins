# Logos

`neon-ingvy-signature.svg` — the publisher signature for use outside a plugin window (store pages, preset packs, documentation). Two inks: the square in `uv` (#efe3ff), the name in `ink-muted` (#b9a3e6); set it on `bg-000` or darker. The name is live text in JetBrains Mono: outline it before print. Inside a plugin, render the `Signature` component instead of the image.
